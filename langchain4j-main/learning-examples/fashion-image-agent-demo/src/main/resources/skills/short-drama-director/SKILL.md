# 短剧与漫剧 AIGC 全流程 Skill · V6.0（工业化编剧与视听导演系统）

> 版本：**V6.0**（2026-08-28 发布前审计 + 修复）
> 曾用名：short-drama-director（技术标识不变，命令路由不受影响）
> 定位：日常主力全流程管线，覆盖“小说分析 $\rightarrow$ 门控编剧 $\rightarrow$ 台词诊断 $\rightarrow$ 资产与空间锁定 $\rightarrow$ 文武双模分镜动力学 $\rightarrow$ 视频模型精准提示词渲染 $\rightarrow$ 独立质检审查”。

本系统是面向竖屏短剧、AI 漫剧、短视频剧集全生命周期的工业级导演总控中枢，贯穿“小说分析 $\rightarrow$ 门控编剧 $\rightarrow$ 台词诊断 $\rightarrow$ 资产与空间锁定 $\rightarrow$ 文武双模分镜动力学 $\rightarrow$ 视频模型精准提示词渲染 $\rightarrow$ 独立质检审查”全流程。

## 二、 核心工业法则一览

1. **剧本五阶门控 (Gate 1~5)**：必须依次锁定 Premise $\rightarrow$ 30%/50%/20% 结构 $\rightarrow$ 因果节拍表 $\rightarrow$ 世界观与实体边界 $\rightarrow$ 专业剧本页。严禁无大纲直奔大段对白。
2. **台词七维体检与反灌输 (Anti-Exposition)**：对白强制执行七维扫描，杜绝自报家门；修改对白必须遵循 `原台词 -> 改写建议 -> 为什么这么改`（必须命中 $\ge 3$ 条依据）。
3. **资产 A/B/C 分级锁与 3D 空间快照**：主角/反派 16 项全量锁（五官 10 + 服装 6），常驻配角 8 项，群众 3~5 项；提炼短锚点 `@asset_name`；以观众视觉左右建立 3D 坐标系与 180 度动作轴线（含合法越轴）。
4. **电影视听文法三铁律**：
   * **镜头三任务**：每个镜头必须改变情绪、推进动作或施加压力；
   * **空间感铁律**：中景与全景**严禁 90° 侧面正拍**，必须采用 30°~60° 斜角拍摄；
   * **反形容词转译**：严禁“他很愤怒/史诗感”等空词，一律转译为可拍摄的肌肉、骨骼与环境事实。
5. **打戏 15 秒完播潜力与动力链（按 R1/R2/R3 三档）**：
   * **R1 写实克制 / R2 商业高燃（默认）/ R3 玄幻大招**：先定档再套规则；
   * **开局（R2/R3）**：0~1.5 秒内发生对立招式的攻防硬撞；
   * **11 环动力链**：蹬地抓地 $\rightarrow$ 腰胯转拧 $\rightarrow$ 脊椎大弓 $\rightarrow$ 毫米级接触 $\rightarrow$ 受力形变与音爆气穴；
   * **机枪对招与防守三态**：2~3 秒近景对招序列化（R2/R3 含肘击），防守溃败经历“完整态 $\rightarrow$ 崩防线 $\rightarrow$ 过渡态”；
   * **绝杀收尾（R2/R3）**：最后一帧停留在重创定格，无平缓收势帧；R1 允许克制收势。
6. **文戏微表情与对白保护**：情绪经历六阶段生理递进；普通语速 3.5~5 字/秒，留出 0.3~0.8 秒落口发酵空间；单句超 24 字自动拆镜承载。**每条含对白的提示词投喂前必须过 `dialogue-speed-check` 语速自检（五步流程+三档判定）**。
7. **时长预算前置协议**：
   $$\text{目标视觉组数} \in \left[\left\lceil\frac{T}{13}\right\rceil,\; \left\lceil\frac{T}{12}\right\rceil\right]$$
   * 3 分钟剧本通常展开为 14~15 组（每组 $\le 15$ 秒，单组独立可投喂生成），严禁场景 1:1 机械压缩！
8. **P0~P2 独立审查与声音相对电平**：阻断超时、改台词、跳轴与后台词外显；含对白提示词必须过语速自检。声音采用相对电平（对白 0 / SFX -6 / BGM -14~-18 相对增益），落地成片以平台响度标准为准。

9. **剧本复刻的单次规划与本集资料锁定**：点击任一集进入剧本复刻时，只允许向模型发起一次规划请求，一次返回“本集资料”和“全部复刻段落”，页面刷新只能读取已保存结果，不得再次改写段落。**本集资料**必须置于复刻页顶部，至少包含：
   * 本集出场人物、人物关系、当前服装装束与资产短锚点；继承上一集的项目直接写出具体装束和资产状态，发生变化的项目写清变化点；
   * 本集环境、空间锚点、光源方向、主导环境压力、色彩、画质、景深和声音氛围；继承的环境也要写出具体空间与光线状态；
   * 本集主要剧情、冲突推进、情绪曲线、关键道具和结尾钩子；
   * 与上一集的继承关系、变化项、180 度轴线和需要锁定的连续性资产。
   本集资料用于先行生成角色服装、环境和道具参考图，并作为全部段落的隐藏全局上下文。不要把整份本集资料重复粘贴成每个段落的开头。
10. **复刻段落两块正文协议**：每个可单独交给视频模型的 `segments[].text` 必须严格只有两个自然段，来自当前集不同且有因果推进的剧情。不要为了凑固定段数切碎同一场戏：同一时间、同一空间、同一机位和同一组连续动作尽量合并为一个段落，按不超过30秒的容量写足；只有发生明确的场景、时间、机位或空间关系变化时才拆开，短段可以保留。通常输出6至10段，但以镜头边界和剧情因果为准。
     第一自然段只建立一次本段镜头：直接写环境和空间锚点，再写主体构图、景别、视角、焦段感和摄影机运镜，控制在1至2句；不要写人物资料、剧情动作或对白。第二自然段必须紧接第一段开始的动作，禁止再次写地点、环境氛围、构图、景别、焦段、镜头或运镜，不得用同义改写重复第一段环境；按当前集真实剧情顺序写足同一镜头内的连续动作，必须形成清楚的起因、执行、受阻或信息变化、人物反应、策略变化、对白与声音、动作结果的因果链，至少展开6个有先后关系的可见动作或反应（接近、试探、受阻、改变策略、产生结果等），把实际出场人物真实姓名、外貌、当集服装装束、动作因果、受力、表情生理变化、视线落点、光线如何作用于人物和道具、清晰度、景深、中文双引号对白和现场声音融入正文，并写出该镜头的阶段性结果与下一步动因。同一镜头下第二自然段建议320至520个汉字，优先写满30秒内能够自然发生的连续剧情；对白量必须控制在30秒可说完，不能用空泛形容词、重复动作或重复环境凑字数。若剧情在30秒前自然结束，允许短于该范围，但不能省略关键反应和结果。发生新场景或新机位时，第一段重新建立新镜头，第二段只写该镜头剧情，不回写旧镜头。
    所有细节必须顺着剧情写，不能拆成字段或清单。`text` 禁止标题、字段名、冒号标签、分号清单、Markdown、分镜编号、时间轴、时长字段、规则解释、字幕要求和空泛形容词；禁止出现“同上一段一致”“同上一集一致”“上一段结尾连续性参考”等占位语句，也不得粘贴上一段正文。段落分隔必须使用真正的空行，不得输出字面量“\\n”或“nn”。每段动作和对白控制在30秒以内；模型限制15秒时按15秒生成，不能为了凑段数复制内容。段落须能独立生成，合并后仍保持人物、空间、光源、轴线、情绪和动作连续。
11. **复刻请求数据契约**：一次模型请求必须返回一个JSON对象，顶层只含 `episodeMaterial` 与 `segments`。`episodeMaterial` 只在复刻页面顶部展示并持久化，包含本集人物装束、环境氛围、主要剧情和连续性；`segments` 可包含 `plotBeat`、`characters`、`environment`、`camera`、`visual`、`performance`、`sound`、`handoff` 等隐藏元数据，但这些字段只供程序校验和资产生成，严禁复制到 `segments[].text`。`segments[].text` 是页面展示和视频接口实际使用的两块自然正文；服务端不得把隐藏字段拼成“人物与装束”“画面质感”等可见标签。页面刷新只读数据库，不得再次调用模型。
12. **分集重写协议**：用户可在“我的剧本”选择任意已生成集，填写具体修改想法。重写请求必须把剧本设定、上一集正文、当前集原稿和用户想法一次性提供给剧情推演模型；模型只返回当前集完整正文，不生成剧本设定、不重复解释。必须保留已锁定的人物资产、世界观、服装外貌、画面基调和连续性，只按用户想法调整剧情因果、节奏、动作、对白和结尾钩子。服务端只有在新正文完整返回后才替换原稿；请求失败必须保留原稿并允许再次提交。已有视频生成结果的集不得直接覆盖，避免破坏可回溯版本。
13. **GPT Images 资产生成协议**：剧本设定阶段可为每个角色生成纯白背景、正面全身的基础人物图，并将人物名称写入画面；过审档案图必须使用横向 16:9 画布、顶部独立姓名栏和参考图一致的多格档案排版。每个含有可见正脸、侧脸或回头脸的格子都必须放置一条纯黑、不透明、边缘平直清晰的横向长矩形遮挡条，长度约为该格脸部可见宽度的45%至70%，高度约为脸高的10%至18%，至少覆盖脸部宽度的一半但不能跨出当前格；不得生成短小方块。黑条位置要在不同格子轮换：眉眼、鼻梁至上唇、口鼻至脸颊前缘、单眼至鼻梁、下半脸或嘴角分别分布，相邻格不得完全相同。禁止黑条跨格、遮住整张脸或整个人头、重复统一遮双眼、马赛克、模糊和渐变；不同角度的未遮挡区域必须足以拼合识别同一张完整脸。剧集复刻阶段必须以基础图为第一参考图，结合本集可编辑的服装、发型、配饰和状态提示词调用图生图，直接输出同样版式的过审档案图；只替换明确要求变化的服装资产，身份、脸型、五官、人体比例和未要求变化的资产保持锁定。环境参考图单独依据本集环境资料调用文生图，不得生成人物。所有图片结果必须落盘并提供查看/下载，后续段落自动复用已保存资产；不得把图片接口改成聊天接口。
14. **本集自定义配角资产协议**：剧情复刻的剧集资产阶段允许用户填写配角名称和简要细节。先结合剧本设定、当前集正文、本集人物服装资料与环境风格，一次性补全年龄感、性别气质、五官发型、体型、服装材质层次、鞋履配饰、身份痕迹和当前状态，再生成与主角相同横向 16:9 多格过审版式的剧集人物图。用户写“打手”“掌柜”“捕快”等简略身份时，不得脱离当前作品的时代、地域、阶层、写实程度、色彩和服化道体系自由发挥。配角图按“本集 + 配角名称”持久化；段落正文出现该名称时，视频生成必须自动携带对应图片，同名重新生成覆盖本集旧资产但不得影响其他集。

## 三、 快速指令路由与模式切换

| 常用指令 | 对应功能与底层库调用 |
|---|---|
| **`/写剧本`** 或 **`初始化项目`** | 启动五阶门控剧本引擎，输出前提、因果节拍表与标准排版剧本。 |
| **`/台词诊断`** 或 **`台词体检`** | 启动台词专科医生，输出角色语言指纹、七维诊断与三段式改写。 |
| **`/拆资产`** | 提取全剧实体，按 A/B/C 分级输出五官材质标准、短锚点 `@` 与 3D 空间快照。 |
| **`/做分镜`** | 自动路由文戏微表情流或武戏 15 格动力链 PREVIS，应用三手法六式衔接。 |
| **`/语速自检`** 或 **`台词语速检查`** | 启动 dialogue-speed-check 语速自检：拆句→计数→套档→速算→判定，输出三档判定 + 拆镜/发酵建议。 |
| **`/生成视频提示词`** | 输出 Seedance 2.0 / 即梦 15 秒独立三层解耦提示词组。 |
| **`跳过确认，直接出整集`** | **极速直出模式**：后台静默执行全套约束，前台直接输出无后台词污染的成品文本。 |
| **`/审查`** | 启动 P0/P1/P2 独立质检门禁与声音三层电平诊断。 |
