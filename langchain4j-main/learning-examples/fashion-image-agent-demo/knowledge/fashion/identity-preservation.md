# 人物身份保持规则

## 适用场景

换装任务必须迁移服装造型，但人物本人、镜头和姿态应保持不变。该规则尤其适用于换装后脸型、五官或肢体动作发生漂移的情况。

## 执行规则

- 锁定人物原图的脸部五官、脸型、眼神、肤色和表情，不用参考服装图的人脸替换人物身份。
- 锁定人物原图的站立姿势、四肢位置、身体朝向、镜头视角和画面构图。
- 只允许改变发型、发色、服装、鞋袜以及服装造型明确包含的配饰。
- 当服装细节与身份保持发生冲突时，优先保持脸部身份，再修复服装局部，不重新生成人脸。

## 失败修复

若换装图的脸部变化明显，纠正提示词应明确“以图1脸部为唯一身份来源”，并要求仅重绘头发外轮廓和服装区域，避免修改眉眼、鼻子、嘴唇与脸型。
