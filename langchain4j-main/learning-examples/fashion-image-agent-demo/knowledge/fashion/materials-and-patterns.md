# 面料、纹样与层次规则

## 适用场景

参考服装包含丝绸、薄纱、蕾丝、皮革、针织、金属装饰、刺绣、印花或多层穿搭，需要提高材质和细节还原度时使用。

## 执行规则

- 材质描述应包含表面属性，例如丝绸的柔和光泽、薄纱的半透明层次、皮革的平滑反光、针织的纤维纹理。
- 纹样需要说明图案类型、主色、分布位置、大小和排列方向，不使用笼统的“同款花纹”。
- 多层服装按由内到外描述上衣、外套、腰封、裙摆和装饰层，保持正确的覆盖关系。
- 金属扣、刺绣边、蕾丝边和缝线属于服装结构的一部分，应跟随对应服装区域，不漂浮到身体或背景。

## 失败修复

若整体颜色正确但材质变成普通布料，纠正提示词应保留已正确的版型，只对目标区域补充材质光泽、透明度、纹理和边缘细节。
