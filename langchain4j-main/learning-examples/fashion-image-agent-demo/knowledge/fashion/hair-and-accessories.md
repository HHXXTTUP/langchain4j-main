# 发型与配饰迁移规则

## 适用场景

参考服装图包含帽子、发带、头纱、发簪、发夹、项链、耳饰、手套、腰带或腿部装饰，或者历史结果容易漏掉头部造型时使用。

## 执行规则

- 从头到脚列出所有清晰可见的配饰，分别说明颜色、材质、形状、大小、数量和佩戴位置。
- 发型迁移必须同时描述发色、长度、卷直、刘海、束发方式和头饰位置，不能只写“替换发型”。
- 头饰与头发存在遮挡关系时，先建立头发轮廓，再按参考图层级放置头饰，保留合理遮挡。
- 成套配饰应保持统一风格和颜色关系，不增加参考图中不可见的首饰。

## 失败修复

若只换了衣服但遗漏发饰，下一轮应把具体发饰名称、颜色和佩戴位置放在纠正提示词最前面，并明确它是必须迁移元素。若工作流遮罩不覆盖头部，提示词无法解决，应调整 RunningHub 工作流遮罩。
