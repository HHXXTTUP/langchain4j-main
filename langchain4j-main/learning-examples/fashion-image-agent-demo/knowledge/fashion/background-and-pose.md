# 背景、姿态与构图保护规则

## 适用场景

换装后背景、人物位置、镜头距离、站姿或肢体动作被意外修改时使用。

## 执行规则

- 背景只能以人物原图为来源，保留场景内容、色调、光线方向、景深和所有固定物体。
- 保持人物在画面中的位置、大小、正面朝向、手臂动作、腿部姿态和脚部落点不变。
- 服装新增的裙摆、袖口或头饰可以改变人物外轮廓，但不能借此改变骨骼姿态或重新裁切画面。
- 新服装的受光方向、阴影强度和环境色应匹配人物原图，使服装融入原有场景。

## 失败修复

若背景发生变化，纠正提示词应把“图1背景逐像素保持”置于高优先级，并要求只编辑人物服装与头发区域。若姿态变化，则明确列出需要锁定的手、腿和身体方向。
