# 换装失败诊断与修复策略

## 先分类再重试

质量检查失败后先判断问题属于服装不匹配、头饰遗漏、身份漂移、背景变化还是图片技术故障。每次纠正只突出最关键的一到三个问题，避免互相冲突的长提示词。

## 修复规则

- 服装版型错误：锁定已正确的人脸、姿态和背景，补充衣领、袖型、腰线、裙长等结构信息。
- 颜色或纹样错误：指出目标区域和准确颜色、纹样分布，不要求重新生成整套人物。
- 头饰遗漏：写明名称、颜色、形状和佩戴位置，并把它列为必须迁移元素。
- 身份漂移：以人物图脸部为唯一身份来源，只允许编辑发型外轮廓和服装区域。
- 背景变化：要求恢复人物原图背景、光线和构图，不采用服装参考图背景。

## 停止条件

同一缺陷连续重试仍无改善，通常说明换装模型、遮罩或工作流节点能力不足。此时应保留质量报告并停止无效重试，转为调整 RunningHub 工作流，而不是继续堆叠提示词。
